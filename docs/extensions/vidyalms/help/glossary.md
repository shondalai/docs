---
title: Plain-language glossary
description: Understand the terms used in VidyaLMS settings, teaching tools, and reports.
---

<div className="table-wrapper" tabIndex={0} role="region" aria-label="Scrollable reference table">

| Term | What it means |
| --- | --- |
| Academy | Your learning site and its courses |
| CMS | The website platform: Joomla or WordPress |
| Course | A collection of learning activities with access and completion rules |
| Module | A section of a course that groups lessons |
| Lesson | One activity, such as reading, a video, quiz, resource, or assignment |
| Course run / cohort | A scheduled group taking a course together |
| Enrolment | The relationship between a learner and a course |
| Access grant / entitlement | A recorded reason someone may enter a course, sometimes with start and end dates |
| Access source | Where a grant came from, such as a purchase, manual enrolment, or organization |
| Prerequisite | Something that must be satisfied before another activity is available |
| Release / drip schedule | A rule that makes learning available at a date or relative time |
| Completion | Meeting the course or lesson's configured requirements |
| Attempt | One recorded sitting or submission of an assessment |
| Rubric | Criteria and scoring guidance used to assess work |
| Pass percentage | The minimum percentage needed for a passing assessment result |
| Gradebook | The instructor's view of assessment results and their totals |
| Regrade | An explicit reassessment of recorded results using the supported correction workflow |
| Question bank | A reusable collection of questions |
| Question pool | Rules that choose eligible questions for an assessment |
| Snapshot | A saved copy of the information used at a particular time, preserving historical meaning |
| Organization | A company or team with its own membership and learning context |
| Unit | A department or subgroup within an organization |
| Course release | Permission for an organization to offer a course; not automatic enrolment for every member |
| Seat | A training place allocated to a person |
| Seat pool | The available capacity for allocating those places |
| Invitation | A request to join or accept a relationship; it may still need verification and acceptance |
| Product mapping | The connection between a shop product and the course access it grants |
| Background account | The account whose permissions an automated enrolment uses |
| Reconciliation | Checking the current source record again to resolve a delayed or missed update |
| Channel | How a message is delivered, such as email or an in-app message |
| Notification rule | The event, audience, timing, and message used for a notification |
| Suppression | A delivery block, often caused by a bounce, complaint, or deliberate hold |
| Token / placeholder | A marker replaced with a value such as a learner name or course title; not the same as a sign-in token |
| Queue | Work waiting to be processed in the background |
| Scheduled task / cron | A regularly triggered process that performs background work |
| Heartbeat | A periodic update from an open lesson player |
| Inactivity timeout | How long a static lesson can remain without activity before time accounting pauses |
| Provider | An installed implementation of a capability; depending on context, it might be a delivery channel, export format, or connected service |
| Credential reference | A name pointing to a securely stored secret, rather than the secret itself |
| AI helper | An assistant offered in a particular teaching or learning task |
| AI route / bridge | The selected connection between an AI task and the service that can perform it |
| Published template | The active version of an email or certificate design |
| Revoked certificate | An issued credential whose validity has been withdrawn |
| LRS | A Learning Record Store that receives compatible activity statements |
| QTI | A format for exchanging questions and assessment information |
| SCORM / cmi5 | Learning-package standards that require a compatible player; not supplied by a normal downloadable ZIP resource |

</div>
