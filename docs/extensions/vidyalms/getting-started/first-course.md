---
title: Create your first course
description: Build, publish, and complete a small course before inviting your learners.
---

Start with a small course you can finish in a few minutes. One reading lesson and a short quiz are enough to check that teaching, enrolment, progress, and completion work together.

On Joomla, open **Components → VidyaLMS**. On WordPress, open **VidyaLMS** in the dashboard. The following steps use the shared course builder.

## 1. Give the course a clear introduction

Open **Courses → New course**, enter a title, and create the course. In **Course details**, add a short summary, a description of what learners will achieve, and a category. Add a cover image if you have one. Set the language and level so people know what to expect.

Save the section before moving on. Course details and lesson editors have separate save controls.

## 2. Add the teaching content

In **Curriculum**, add a module called “Getting started.” Add a **Reading** lesson with a short explanation and one thing for the learner to try. Save it.

Add a **Quiz** lesson. Create a single-choice question, mark the correct answer, assign its points, and save. Set the passing score and allowed attempts in the quiz settings. Preview the question to check that the instructions and answers make sense.

You can reorder lessons by dragging them or by using their ordering controls. Keep the first example short; the [lesson guide](../courses/lessons.md) covers videos, downloads, assignments, and optional lesson types.

## 3. Choose access and completion

In **Access → Visibility & pricing**, choose **Free** for this first test. Make the course discoverable in the catalogue if that is your intention. Check that **Settings → Catalogue & enrolment → Allow self-enrolment** is enabled if learners should join themselves.

In **Access → Schedule & progression**, choose whether learners can work in any order or must follow the sequence.

In **Assessment & completion**, choose a completion rule appropriate to the course. For this example, require the lessons to be completed. If passing a final quiz is essential, configure that requirement explicitly; merely adding a quiz does not explain your intended course completion policy.

Save each changed section.

## 4. Publish and test as a learner

Open **Publishing**, review the readiness checks, and publish the course. Then use a separate ordinary learner account to:

1. Find the course in the catalogue.
2. Join it and select **Start learning**.
3. Complete the reading lesson and submit the quiz.
4. Leave and return through **My learning** to check resume behaviour.
5. Confirm the expected completion result.

An administrator preview helps with content, but it does not prove that a learner has the correct access. If something stays locked, inspect [access and progression](../courses/access-progression.md).

## 5. Add the next feature

Once the simple course works, add an [assignment](../courses/assignments.md), select a [certificate template](../credentials/certificates.md), or connect a [paid shop product](../commerce/overview.md). Change one part at a time so you can tell which setting produced the result.

Check the learner record and [reports](../reports/reports.md) to see the evidence from your test. Keep test accounts clearly named so they do not get confused with real learners.
