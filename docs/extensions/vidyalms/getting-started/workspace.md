Open **Components → VidyaLMS** in Joomla or **VidyaLMS** in the WordPress dashboard. The workspace brings teaching, learner support, and academy settings together.

## Start with the dashboard

The dashboard summarizes enrolments, published courses, completion, and issued certificates. Review the selected time period before comparing figures. Some totals describe the current academy while activity charts describe the selected period.

Use **Needs attention** to find work such as drafts or pending actions. Open the relevant record to see the details behind a count. The activity feed helps you review recent recorded changes.

Use refresh when you need the latest values. If a chart says there was no activity in the previous period, it cannot provide a meaningful percentage comparison with that period.

## Use navigation and search

The workspace sidebar groups content, people, reporting, communication, and system tools. **Find a page** helps locate a management screen. The minimize control reduces the sidebar to icons when you want more working space; expand it to see the full labels again.

The workspace appearance control changes the administrative experience. Your public site's template and learner experience settings also influence what learners see.

## Work with lists

In **Courses**, search by title, filter by category or publication state, choose a sort order, and switch between the available list and grid views. Clear filters when a course appears to be missing.

Open the course to edit it. Publication and trash actions affect learner access, so read their confirmation before using them. The [course builder guide](../courses/course-builder.md) explains draft, published, archived, and trashed states.

Question banks have their own search, status, ownership, and editing tools. Course ownership and site-wide sharing determine where a bank can be used. See [question banks](../courses/question-banks.md).

## Choose the right workspace for a task

| Task | Open |
| --- | --- |
| Edit teaching material | Courses and the course builder |
| Assess a learner's submission | Course Gradebook or the teaching assessment queue |
| Find a person and their learning | Learners |
| Add or review course membership | Enrolments |
| Manage a company or department | Organizations |
| Review outcomes or export evidence | Reports |
| Change what learners receive | Notifications and Email templates |
| Investigate background processing | System health |
| Change academy configuration | Settings |

</div>

Instructors may use the frontend teaching workspace instead of the full site administration area. Their available courses and actions follow the same permission boundaries.

Before sharing the academy with learners, work through the [launch checklist](launch-checklist.md).
